# moodies assets

Drop these files in this folder. The page picks them up automatically, and each one has a built-in fallback until it's here:

| File | Used for | Fallback until it's added |
| --- | --- | --- |
| `key-art.jpg` | Full-bleed hero background (the Moodies key art still) | Animated glow and hanging-bulb illustration |
| `legal-review.mp4` | "Legal Review" commercial in the Now Playing section | "Legal Review" title card |
| `legal-review-poster.jpg` | Poster frame shown before the video plays | Black frame |

To host the commercial on YouTube instead, set `CONFIG.legalReviewYouTubeId` near the bottom of `../index.html`.
